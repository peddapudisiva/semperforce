# Semper Force

Marketing website for Semper Force — "The Operating System for Educational Leadership." A static, multi-page site built with plain HTML, CSS and JavaScript.

## Pages

- `index.html` — Home
- `problem.html` — The Problem
- `solution.html` — Our Solution
- `sample-engagement.html` — Sample Engagement
- `outcome.html` — Outcome
- `about.html` — About
- `contact.html` — Contact

## Running locally

```bash
python -m http.server 8080
```

Then open `http://localhost:8080` in a browser.
